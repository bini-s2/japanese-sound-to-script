## 3. Quiz Structure

```text
일본어 곡 제목
→ 제목의 뜻 객관식
→ 정답
→ 히라가나 읽기
→ (발음 보기) 영문 로마자
→ 핵심 단어·한자·조사·활용
→ 곡명·가수명·공식 출처
→ 저장 또는 다음 문제
```

문제 전에는 제목만 보여주고 가수명은 정답 피드백에서 공개합니다. 곡의 인지도가 아니라 일본어 표현을 읽고 해석해 답하게 하기 위함입니다.

## 5. Rights & Asset Rules

> Copyright review: 2026-09-16 · 현재 후보 335개 중 곡 제목 자체의 저작권 때문에 제외할 항목은 없음  
> Basis: JASRAC은 악곡 제목은 일반적으로 저작물로 보지 않으므로 제목만 표시할 때 이용신청이 필요 없다고 안내함

### Allowed in V1

- 곡 제목과 아티스트명을 식별 목적의 일반 텍스트로 표시
- 제목의 히라가나 읽기, 자체 작성한 한국어 뜻, 단어·문법 설명 제공
- 공식 곡 정보 페이지로 연결되는 일반 텍스트 링크 제공

### Requires Separate Permission or Review

- 가사 일부 또는 전체, 음원, 뮤직비디오 화면, 앨범아트·재킷 이미지 사용
- 공식 로고, 고유 서체·타이포그래피, 홍보 이미지 복제
- 특정 곡 제목이나 아티스트명을 서비스명·로고·상품명처럼 사용하는 경우의 상표 검토
- 특정 아티스트의 공식 서비스·협업 서비스로 오인될 수 있는 화면 구성과 문구

## 7. Random Selection Rules

```text
검수 완료 제목 풀
→ 아직 이번 세션에서 안 나온 제목 중 무작위
→ 사용자가 처음 보는 제목 우선
→ 세션 안에서 중복 출제하지 않음
→ 전체를 모두 본 뒤 다시 섞기
```

- 같은 제목을 한 세션에서 반복하지 않습니다.
- 처음 보는 제목을 우선하되, 사용자가 ‘헷갈려요’를 선택한 제목은 다음 세션에서 우선 출제할 수 있습니다.
- 아티스트나 문자 유형이 한쪽에 연속으로 몰리지 않도록 가능한 범위에서 분산합니다.
- 검수가 끝나지 않은 제목은 랜덤 풀에 넣지 않습니다.
- 새로운 제목은 배포 없이 데이터만 추가할 수 있는 구조를 목표로 합니다.

- 순수 영문·숫자 공식 제목은 일본어 읽기 학습 대상에서 제외합니다.
- 화면에 로마자로 표시됐더라도 공식 일본어 원제가 명확하면 일본어 제목으로 정규화합니다.

- 제외된 순수 영문 제목과 배치별 중복 내역은 Git 기록에서 확인할 수 있습니다.
