## 2. Content Pool

- 1차 첨부 시드: 순수 영문 `Brand New`를 제외한 일본어 제목 17개
- 2차 플레이리스트 첨부: 일본어 문자가 포함된 고유 제목 118개
- 3차 플레이리스트 첨부: 일본어 제목 신규 149개
- 4차 플레이리스트 첨부: 일본어 제목 신규 51개
- 현재 후보 풀: 중복을 제거한 총 335개
- 고정된 완료 수량이나 최대 개수는 두지 않습니다.
- 새로운 J-POP·애니·영화·드라마 제목을 검수하는 대로 계속 추가합니다.
- Low-fi와 초기 기능 테스트는 현재 335개 후보로 시작할 수 있습니다.
- 출시 시점에는 확보된 모든 검수 완료 제목을 사용합니다.

## 3. Quiz Structure

```text
일본어 곡 제목
→ 제목의 뜻 객관식
→ 정답
→ 히라가나 읽기
→ (발음 보기) 영문 로마자
→ 핵심 단어·한자·조사·활용
→ 곡명·가수명·공식 출처
→ 저장 또는 다음 문제
```

문제 전에는 제목만 보여주고 가수명은 정답 피드백에서 공개합니다. 곡의 인지도가 아니라 일본어 표현을 읽고 해석해 답하게 하기 위함입니다.

## 4. Content Types

- **한자·문장형:** 僕にはどうしてわかるんだろう, 君を知らない, 嘘じゃないよ
- **한자 표현형:** 怪獣の花唄, 靴の花火, 灯火, 春泥棒, 我逢人, 狭心症, 慶びの種, 僕のこと
- **가타카나형:** ハルノヒ, ライラック, スターダスト, ア・プリオリ
- **히라가나·언어유희형:** うたたね, しわあわせ
- 순수 영문·알파벳 제목은 일본어 읽기 학습 대상에서 제외합니다.

## 5. Rights & Asset Rules

- 곡 제목과 가수명만 일반 텍스트로 사용합니다.
- 첨부 화면의 앨범아트·썸네일·로고는 서비스 자산으로 복사하지 않습니다.
- 가사·음원·뮤직비디오 캡처는 V1에 포함하지 않습니다.
- 각 항목에는 공식 곡 정보 URL과 확인일을 기록합니다.
- 실제 서비스가 특정 가수·레이블의 공식 서비스처럼 보이지 않게 합니다.

## 7. Random Selection Rules

```text
검수 완료 제목 풀
→ 아직 이번 세션에서 안 나온 제목 중 무작위
→ 사용자가 처음 보는 제목 우선
→ 세션 안에서 중복 출제하지 않음
→ 전체를 모두 본 뒤 다시 섞기
```

- 같은 제목을 한 세션에서 반복하지 않습니다.
- 처음 보는 제목을 우선하되, 사용자가 ‘헷갈려요’를 선택한 제목은 다음 세션에서 우선 출제할 수 있습니다.
- 아티스트나 문자 유형이 한쪽에 연속으로 몰리지 않도록 가능한 범위에서 분산합니다.
- 검수가 끝나지 않은 제목은 랜덤 풀에 넣지 않습니다.
- 새로운 제목은 배포 없이 데이터만 추가할 수 있는 구조를 목표로 합니다.
