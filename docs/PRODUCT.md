# Product Definition

## 1. Product Summary

**Japanese Sound to Script**는 일본어를 귀로 익힌 학습자가 소리·문자·뜻을 연결하도록 돕는 AI 기반 학습 서비스입니다.

핵심 타깃은 다음과 같습니다.

- 애니, J-POP, 드라마 등으로 일본어를 오래 접했다.
- 일본어 발음과 의미는 어느 정도 익숙하다.
- 히라가나는 읽을 수 있지만 한자·가타카나에서 자주 막힌다.
- 말은 어느 정도 되는데 읽고 쓰기가 약하다.
- 기존 번역기나 커리큘럼형 학습에서 개인적인 궁금증이 충분히 해소되지 않는다.

## 2. Core Problem

사용자의 머릿속에는 이미 많은 일본어 소리가 저장되어 있지만, 그 소리가 실제 일본어 표기와 연결되지 않습니다.

예:

```text
카와라나이 모노
→ 발음과 의미는 익숙함
→ 変わらないもの 를 보면 즉시 연결되지 않음
```

이 서비스는 새로운 표현을 무작정 외우게 하기보다 **이미 알고 있는 소리에 글자를 붙이는 경험**을 만듭니다.

## 3. Value Proposition

> 귀로 알고 있던 일본어를, 읽고 쓸 수 있는 일본어로.

기존 학습이 `커리큘럼 → 문제 풀이` 중심이라면, 이 서비스는 `호기심 → 탐색 → 이해 → 회상`에서 시작합니다.

사용자가 배우고 싶은 표현을 서비스가 먼저 정하지 않습니다.

## 4. Learning Loop

`Sound → Script → Meaning → Recall`

### Sound

사용자가 기억하는 발음을 그대로 입력하거나 실제 콘텐츠에서 듣습니다.

### Script

가능한 일본어 원문, 히라가나 읽기, 한자 표기를 연결합니다.

### Meaning

뜻, 문법 구조, 원형, 뉘앙스, 유사 표현을 이해합니다.

### Recall

저장한 표현과 오답을 다시 꺼내며 장기 기억으로 연결합니다.

## 5. Core Modes

### HEARD — 들은 일본어 찾기

한글 음차를 입력하면 가능한 일본어 표현을 찾습니다.

예:

```text
Input: 카와라나이 모노
Output: 変わらないもの / かわらないもの / 변하지 않는 것
```

동음·유사음이 여러 개일 경우 후보를 제시하고 문맥으로 구분합니다.

### WRITE — 말하고 싶은 것 표현하기

한국어로 입력한 문장을 일본어로 바꾼 뒤 다양한 맥락으로 확장합니다.

- 자연스러운 표현
- 캐주얼한 표현
- 조금 더 문학적인 표현
- 일기에서 쓸 만한 표현
- 비슷한 문장

### LISTEN — 실제 콘텐츠로 연결하기

실제 콘텐츠의 특정 구간을 바탕으로 2단계 퀴즈를 제공합니다.

1. 들린 일본어와 맞는 원문 고르기
2. 해당 문장의 뜻 고르기

정답 확인 뒤 읽기, 문법, 유사 표현으로 확장합니다.

## 6. UX Principles

### 6.1 강요하지 않는다

틀렸을 때 반드시 다시 풀게 하지 않습니다.

- 다시 해보기
- 다음으로

중 선택할 수 있게 합니다.

### 6.2 사용자의 기존 지식을 존중한다

초보자 취급하지 않고, 이미 알고 있는 소리와 의미를 학습 자산으로 봅니다.

### 6.3 뜻보다 연결을 만든다

정답만 보여주지 않고 `소리 ↔ 히라가나 ↔ 한자 ↔ 의미`의 연결을 시각적으로 드러냅니다.

### 6.4 실제 사용 맥락을 알려준다

사전적 의미만 제공하지 않고 아래와 같은 맥락을 함께 보여줍니다.

- 일상 회화
- 가사
- 문어체
- 캐주얼
- 문학적 표현

### 6.5 설명 과부하를 피한다

AI가 많은 정보를 줄 수 있어도 처음부터 모두 펼치지 않습니다.

기본 결과는 간결하게 제공하고, 문법·뉘앙스·유사 표현은 사용자가 필요할 때 확장합니다.

## 7. Brand Role — 소복이네

소복이네 캐릭터는 학습의 주인공이 아니라 **학습 흐름을 도와주는 가이드**입니다.

활용 후보:

- 온보딩
- Empty State
- 정답·오답 피드백
- 복습 알림
- 학습 힌트
- 마이크로 인터랙션

캐릭터 비중이 학습 정보보다 커지지 않도록 합니다.

## 8. Research Direction

### Desk Research

- Duolingo
- 말해보카
- 일본어 사전/번역기
- 일본어 학습 커뮤니티 후기

### User Research

주요 질문:

- 일본어를 어떻게 처음 접했는가?
- 들으면 아는데 표기로는 모르는 표현이 있는가?
- 한자 때문에 읽기가 끊긴 경험이 있는가?
- 번역기는 어떤 순간에 사용하는가?
- 기존 학습 서비스에서 기억에 잘 안 남는 이유는 무엇인가?

### Usability Test

예시 Task:

> 애니에서 `카와라나이 모노`라는 말을 들었습니다. 이 서비스에서 실제 일본어 표기와 뜻을 찾아보세요.

관찰 항목:

- 한글 발음 입력 방식을 바로 이해하는가?
- 어떤 정보를 가장 먼저 확인하는가?
- 후보 표현이 여러 개일 때 혼란이 있는가?
- 한자/읽기/뜻/문법 중 어떤 정보가 가장 유용한가?

## 9. Product Goal

포트폴리오용 토이 프로젝트에 머물지 않고, 실제 사용자가 반복해서 쓰고 비용을 지불할 가능성이 있는 제품인지 검증합니다.

초기 목표는 기능 수가 아니라 **핵심 학습 루프가 실제로 유용한지 증명하는 것**입니다.
