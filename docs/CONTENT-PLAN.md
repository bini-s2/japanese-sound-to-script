# V1 Content Plan

> Source: Home structure sketch  
> Goal: 발음 검색만 가능한 도구가 아니라, 사용자가 바로 일본어를 읽고 풀어볼 수 있는 학습 홈 제공

## 1. Home Content Architecture

V1 홈에는 여섯 개의 학습 진입점을 둡니다.

1. **발음 검색**
2. **무작위 연습**
3. **저장·복습**
4. **선택 학습**
5. **콘텐츠로 연습하기**
6. **그림 퀴즈**

별도 기능 탭을 늘리기보다 홈에서 각 학습 모듈로 진입하고, 저장 표현만 전역 내비게이션으로 유지합니다.

## 2. 발음 검색

기존 V1의 핵심 기능입니다.

```text
한글 발음 입력
→ 가장 유사한 일본어 후보 2~3개
→ 후보 선택
→ 결과 상세
→ 저장
```

결과에는 일본어 표기·히라가나·뜻·핵심 문법·유사 후보 차이·선택형 한국어 발음 힌트를 제공합니다.

## 3. 무작위 연습

사용자가 별도 검색 없이 바로 문제를 풀 수 있는 진입점입니다.

### Quick Word

- 무작위 일본어 단어
- 일본어 표기 먼저 노출
- 읽기 확인
- 뜻 고르기
- 히라가나·가타카나·한자 구분

### Quick Sentence

- 무작위 짧은 문장
- 표기 읽기
- 뜻 떠올리기
- 뜻 객관식
- 핵심 단어·문법 한 줄

### Mixed Script

히라가나만이 아니라 가타카나·한자가 섞인 실제 표기에 익숙해지는 문제입니다.

```text
히라가나
+ 가타카나
+ 기초 한자
→ 한 문장 안에서 읽기
```

무작위 연습에서 유용한 표현은 개인 표현장에 저장할 수 있습니다.

## 4. 저장·복습

### Bookmark

저장 대상을 구분합니다.

- 단어
- 문장
- 발음 검색 결과
- 무작위 연습 문제
- 선택 학습 문제
- 콘텐츠 문제
- 그림 퀴즈 표현

### Review

```text
복습하기
→ 문제 수 직접 선택
→ 헷갈린 표현 우선 + 나머지 무작위
→ 표기 읽기
→ 뜻 떠올리기
→ 뜻 객관식
→ 알았어요 / 헷갈려요
```

저장 직후 학습을 강요하지 않고 사용자가 원할 때 시작합니다.

## 5. 선택 학습

학습자가 필요한 문자 영역을 직접 선택합니다.

### Hiragana

- 전체 표
- 글자와 소리 연결
- 행별 연습
- 단어 속 글자 찾기
- 읽기 퀴즈

### Katakana

- 전체 표
- 히라가나와 대응 비교
- 외래어·콘텐츠 단어
- 비슷한 글자 구분
- 읽기 퀴즈

### Kanji

- 초급·생활 한자
- 음보다 실제 단어와 상황 중심
- 한자→히라가나 읽기
- 한자→뜻 연결
- 문장 안에서 알아보기

한자 학습은 단독 암기보다 노래·여행·대화에서 접한 단어를 우선합니다.

## 6. 콘텐츠로 연습하기

실제 콘텐츠를 좋아하는 학습 동기를 살리되, V1은 권리를 확보한 자체 콘텐츠로 구성합니다.

### Original Song

- 직접 작성·수정한 일본어 가사
- 권리를 확인한 AI 음악 도구로 제작한 자체 곡
- 특정 구간 듣기
- 들린 일본어 가사 고르기
- 뜻 고르기
- 표기·읽기·문법 확인

### Situation Dialogue

실제 드라마 명대사를 직접 수록하지 않고 드라마처럼 맥락이 있는 자체 상황 대화를 만듭니다.

초기 상황:

- 식당에서 주문하기
- 호텔 체크인·체크아웃·짐 맡기기
- 지하철에서 역·노선·출구 묻기
- 직원의 예상하지 못한 답변
- 친구와의 짧은 일상 대화

문제 유형:

- 들린 문장 고르기
- 다음 대답 고르기
- 문장의 뜻 고르기
- 상황에 맞는 표현 고르기

### Rights Rule

- 실제 J-POP 가사와 드라마 대사를 서비스 DB에 직접 수록하지 않습니다.
- 자체 가사·자체 상황 대화를 기본 콘텐츠로 사용합니다.
- 실제 작품은 공식 임베드·사용 허가·라이선스가 확보된 경우에만 확장합니다.
- 특정 곡·가수·배우의 목소리나 스타일을 모방하지 않습니다.

## 7. 그림 퀴즈

소복이네 캐릭터와 상황 그림을 학습 정보로 활용합니다.

### Formats

#### Picture → Word

그림을 보고 알맞은 일본어 단어를 고릅니다.

#### Picture → Sentence

그림 속 상황과 맞는 문장을 고릅니다.

#### Dialogue O/X

캐릭터의 일본어 대사가 그림과 자연스럽게 맞는지 판단합니다.

예:

```text
소복이네 캐릭터 두 명이 처음 만난 장면
「お名前は何ですか？」
→ 이 상황에 자연스러운 표현인가요?
○ / ×
```

정답 뒤에는 읽기·뜻·상황 설명을 제공합니다. 캐릭터는 장식이 아니라 문제의 맥락을 전달하는 역할을 합니다.

## 8. Initial Content Production Target

아래 수량은 V1 콘텐츠 제작량을 통제하기 위한 초기 목표이며 테스트 후 조정합니다.

| Content | Initial target |
|---|---:|
| 무작위 단어 | 30 |
| 무작위 짧은 문장 | 20 |
| 히라가나 | 기본 46자 전체 |
| 가타카나 | 기본 46자 전체 |
| 기초·생활 한자 | 20 |
| 자체 상황 대화 | 5개 상황 × 3문제 |
| 자체 노래 | 1곡 × 5개 구간 |
| 소복이네 그림 퀴즈 | 10 |

총량보다 한 문제의 정확성·자연스러운 일본어·학습 설명 품질을 우선합니다.

## 9. Content Data Requirements

각 콘텐츠 항목은 다음 정보를 가집니다.

- id
- contentType
- japanese
- kana
- koreanPronunciation
- meaning
- context
- difficulty
- scriptType
- keyWords
- grammar
- distractors
- correctAnswer
- explanation
- rightsSource
- createdAt
- reviewedAt

그림 퀴즈는 imageAssetId, 노래 문제는 audioAssetId와 clipStart·clipEnd를 추가합니다.

## 10. Quality Guardrails

- 모든 일본어 문장과 정답은 별도 검토합니다.
- 오답 선택지는 명백한 오타가 아니라 실제로 헷갈릴 만한 차이로 만듭니다.
- 한국어 발음은 기본으로 숨깁니다.
- 문법 설명은 한 문제당 핵심 한 가지를 우선합니다.
- 실제 콘텐츠 제목·가사·대사를 무단으로 복제하지 않습니다.
- AI 생성 가사·음원·문장도 사람의 검토와 수정 없이 바로 게시하지 않습니다.
- 소복이네 그림은 정답을 추측하기 위한 장식이 아니라 상황 이해에 필요한 정보로 사용합니다.

## 11. Home Priority

홈의 정보 우선순위:

1. 발음 검색
2. 바로 연습하기 — 무작위 단어·문장
3. 이어서 학습하기 — 저장·복습
4. 선택 학습 — 히라가나·가타카나·한자
5. 콘텐츠로 연습하기 — 자체 노래·상황 대화
6. 그림 퀴즈 — 소복이네

홈에서 모든 콘텐츠를 한 번에 펼치지 않고 섹션별 대표 카드와 더보기로 구성합니다.
