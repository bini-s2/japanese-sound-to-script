# V1 Content Plan

> Source: Home structure sketch  
> Goal: 발음 검색만 가능한 도구가 아니라, 사용자가 바로 일본어를 읽고 풀어볼 수 있는 학습 홈 제공

## 1. Home Content Architecture

V1 홈에는 여섯 개의 학습 진입점을 둡니다.

1. **발음 검색**
2. **무작위 연습**
3. **저장·복습**
4. **선택 학습**
5. **콘텐츠로 연습하기**
6. **그림 퀴즈**

별도 기능 탭을 늘리기보다 홈에서 각 학습 모듈로 진입하고, 저장 표현만 전역 내비게이션으로 유지합니다.

## 2. 발음 검색

기존 V1의 핵심 기능입니다.

```text
한글 발음 입력
→ 가장 유사한 일본어 후보 2~3개
→ 후보 선택
→ 결과 상세
→ 저장
```

결과에는 일본어 표기·히라가나·뜻·핵심 문법·유사 후보 차이를 제공합니다. 히라가나 옆의 작은 `(발음 보기)` 버튼을 누르면 영문 로마자 발음을 추가로 보여줍니다.

## 3. 무작위 연습

사용자가 별도 검색 없이 바로 문제를 풀 수 있는 진입점입니다.

### Quick Word

- 무작위 일본어 단어
- 일본어 표기 먼저 노출
- 읽기 확인
- 뜻 고르기
- 히라가나·가타카나·한자 구분

### Quick Sentence

- 무작위 짧은 문장
- 표기 읽기
- 뜻 떠올리기
- 뜻 객관식
- 핵심 단어·문법 한 줄

### Mixed Script

히라가나만이 아니라 가타카나·한자가 섞인 실제 표기에 익숙해지는 문제입니다.

```text
히라가나
+ 가타카나
+ 기초 한자
→ 한 문장 안에서 읽기
```

무작위 연습에서 유용한 표현은 개인 표현장에 저장할 수 있습니다.

## 4. 저장·복습

### Bookmark

저장 대상을 구분합니다.

- 단어
- 문장
- 발음 검색 결과
- 무작위 연습 문제
- 선택 학습 문제
- 콘텐츠 문제
- 그림 퀴즈 표현

### Review

```text
복습하기
→ 문제 수 직접 선택
→ 헷갈린 표현 우선 + 나머지 무작위
→ 표기 읽기
→ 뜻 떠올리기
→ 뜻 객관식
→ 알았어요 / 헷갈려요
```

저장 직후 학습을 강요하지 않고 사용자가 원할 때 시작합니다.

## 5. 선택 학습

학습자가 필요한 문자 영역을 직접 선택합니다.

### Hiragana

- 전체 표
- 글자와 소리 연결
- 행별 연습
- 단어 속 글자 찾기
- 읽기 퀴즈

### Katakana

- 전체 표
- 히라가나와 대응 비교
- 외래어·콘텐츠 단어
- 비슷한 글자 구분
- 읽기 퀴즈

### Kanji Expressions

- 한자 한 글자나 전체 음독·훈독 목록보다 실제로 자주 쓰는 **표현 단위**로 학습
- 노래·일상 대화·여행에서 먼저 들었을 가능성이 높은 표현 우선
- 일본어 표기 → 읽기 → 뜻 → 자연스러운 예문의 순서로 연결
- 한자→히라가나 읽기, 한자→뜻 연결, 문장 안에서 알아보기
- 비슷한 한국어 뜻이라도 일본어에서 쓰임이 다른 표현을 비교

예를 들어 `心（こころ）`는 마음·내면, `胸（むね）`는 가슴과 가슴속 감정, `気持ち（きもち）`는 현재 느끼는 기분·감정으로 구분합니다. `君（きみ）`는 모든 상대에게 쓰는 중립적인 ‘너’가 아니라 친한 관계나 노래 가사에서 자주 보이는 표현임을 함께 알려줍니다.

초기 목록은 JLPT 급수 순서나 한자 글자 빈도만 따르지 않습니다. 사용자가 소리로는 이미 알 가능성이 높고 실제 문장에서 다시 만날 표현을 우선합니다. 상세 목록과 예문은 [KANJI-CONTENT.md](./KANJI-CONTENT.md)를 따릅니다.

한자 표현 표는 처음 20개를 보여주고, 표 아래의 `더 많은 한자 표현 보기` 텍스트 버튼을 누르면 다음 20개를 같은 표에 추가해 총 40개를 보여줍니다.

## 6. 콘텐츠로 연습하기

실제 J-POP에 대한 관심을 학습 동기로 활용하되, V1은 곡의 **제목 텍스트만** 학습 문제로 사용합니다.

### J-POP Title Quiz

```text
君を知らない
→ 제목의 뜻 고르기
→ 정답 확인
→ きみをしらない
→ (발음 보기) kimi o shiranai
→ 핵심 단어·문법
→ 곡명·가수명 출처 확인
```

- 실제 J-POP 곡 제목을 일본어 문제로 제시
- 제목의 한국어 뜻을 객관식으로 선택
- 정답 뒤 히라가나 읽기와 선택형 영문 로마자 발음 제공
- 제목에 포함된 핵심 단어·조사·부정형 등을 짧게 설명
- 곡명과 가수명은 출처 확인을 위한 일반 텍스트로 표시
- 유용한 제목 표현은 개인 표현장에 저장 가능
- V1에서는 음원·가사·앨범아트·로고·뮤직비디오 이미지를 사용하지 않음
- 사용자가 첨부한 기존 J-POP 정리에서 18개 제목을 초기 후보로 확정하고, 나머지 2개를 추가 선정

상세 후보 목록과 검수 상태는 [JPOP-TITLE-CONTENT.md](./JPOP-TITLE-CONTENT.md)를 따릅니다.
### Situation Dialogue

실제 드라마 명대사를 직접 수록하지 않고 드라마처럼 맥락이 있는 자체 상황 대화를 만듭니다.

초기 상황:

- 식당에서 주문하기
- 호텔 체크인·체크아웃·짐 맡기기
- 지하철에서 역·노선·출구 묻기
- 직원의 예상하지 못한 답변
- 친구와의 짧은 일상 대화

문제 유형:

- 들린 문장 고르기
- 다음 대답 고르기
- 문장의 뜻 고르기
- 상황에 맞는 표현 고르기

### Rights Rule

- V1에서 실제 J-POP은 곡 제목과 가수명이라는 최소한의 텍스트 정보만 사용합니다.
- 실제 가사·음원·앨범아트·로고·뮤직비디오 캡처를 서비스 DB에 수록하지 않습니다.
- 제목은 통상 저작권 보호 대상이 아니지만, 상표·부정경쟁·플랫폼 약관 등 별도 권리는 콘텐츠별로 확인합니다.
- 서비스가 특정 가수·레이블의 공식 서비스인 것처럼 표현하지 않습니다.
- 곡 정보의 정확한 출처와 확인일을 기록합니다.
- 실제 드라마 대사는 직접 수록하지 않고 자체 상황 대화를 사용합니다.
- 음원이나 공식 이미지는 추후 정식 라이선스 또는 허용된 공식 임베드가 확보된 경우에만 확장합니다.

## 7. 그림 퀴즈

소복이네 캐릭터와 상황 그림을 학습 정보로 활용합니다.

### Formats

#### Picture → Word

그림을 보고 알맞은 일본어 단어를 고릅니다.

#### Picture → Sentence

그림 속 상황과 맞는 문장을 고릅니다.

#### Dialogue O/X

캐릭터의 일본어 대사가 그림과 자연스럽게 맞는지 판단합니다.

예:

```text
소복이네 캐릭터 두 명이 처음 만난 장면
「お名前は何ですか？」
→ 이 상황에 자연스러운 표현인가요?
○ / ×
```

정답 뒤에는 읽기·뜻·상황 설명을 제공합니다. 캐릭터는 장식이 아니라 문제의 맥락을 전달하는 역할을 합니다.

## 8. Initial Content Production Target

아래 수량은 V1 콘텐츠 제작량을 통제하기 위한 초기 목표이며 테스트 후 조정합니다.

| Content | Initial target |
|---|---:|
| 무작위 단어 | 30 |
| 무작위 짧은 문장 | 20 |
| 히라가나 | 기본 46자 전체 |
| 가타카나 | 기본 46자 전체 |
| 자주 쓰는 한자 표현 | 총 40개 표현 + 예문 · 최초 20개 노출 |
| 자체 상황 대화 | 5개 상황 × 3문제 |
| J-POP 제목 퀴즈 | 목표 20개 · 현재 18개 후보 확정 |
| 소복이네 그림 퀴즈 | 10 |

총량보다 한 문제의 정확성·자연스러운 일본어·학습 설명 품질을 우선합니다.

## 9. Content Data Requirements

각 콘텐츠 항목은 다음 정보를 가집니다.

- id
- contentType
- japanese
- kana
- romanization
- meaning
- context
- difficulty
- scriptType
- keyWords
- grammar
- distractors
- correctAnswer
- explanation
- rightsSource
- createdAt
- reviewedAt

그림 퀴즈는 imageAssetId를 추가합니다. J-POP 제목 문제는 songTitle, artistName, sourceUrl, sourceCheckedAt을 추가합니다.

## 10. Quality Guardrails

- 모든 일본어 문장과 정답은 별도 검토합니다.
- 오답 선택지는 명백한 오타가 아니라 실제로 헷갈릴 만한 차이로 만듭니다.
- 영문 로마자 발음은 히라가나 옆의 작은 `(발음 보기)` 버튼을 누른 뒤에만 보여줍니다.
- 문법 설명은 한 문제당 핵심 한 가지를 우선합니다.
- J-POP은 제목과 가수명만 사용하고 가사·음원·앨범아트·로고·영상 이미지는 복제하지 않습니다.
- 제목·가수명·읽기·뜻·출처의 정확성을 게시 전에 검수합니다.
- 소복이네 그림은 정답을 추측하기 위한 장식이 아니라 상황 이해에 필요한 정보로 사용합니다.

## 11. Home Priority

홈의 정보 우선순위:

1. 발음 검색
2. 바로 연습하기 — 무작위 단어·문장
3. 이어서 학습하기 — 저장·복습
4. 선택 학습 — 히라가나·가타카나·한자
5. 콘텐츠로 연습하기 — J-POP 제목 퀴즈·상황 대화
6. 그림 퀴즈 — 소복이네

홈에서 모든 콘텐츠를 한 번에 펼치지 않고 섹션별 대표 카드와 더보기로 구성합니다.
