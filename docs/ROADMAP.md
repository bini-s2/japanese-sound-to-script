# Roadmap

## Phase 0 — Concept

현재 단계.

목표:

- 문제 정의
- 핵심 타깃 정의
- 현재 학습 상태 파악
- 학습 루프 정의
- MVP 범위 확정

완료:

- `Sound → Script → Meaning → Recall`
- HEARD / WRITE / LISTEN 구조
- 소복이네 브랜드 활용 방향
- 실제 판매 가능성 검토

## Phase 1 — MVP

핵심 기능:

- 한글 발음 입력
- 일본어 표기 추론
- 히라가나 읽기
- 한국어 의미
- 표현 분석
- 비슷한 표현
- 저장

기술 목표:

- 웹 기반
- 반응형 UI
- AI API 연동
- LocalStorage 또는 간단한 DB 저장

제품 목표:

- 사용자 1호로 직접 반복 사용
- 최소 10개 이상의 실제 검색 사례 기록
- 어떤 정보가 가장 유용한지 관찰

## Phase 2 — Learning Status & UX Validation

시험 점수보다 현재 학습 상태와 실제 사용 변화를 먼저 파악합니다.

### Learning Status Mapping

- 히라가나·가타카나 인식 속도
- 익숙한 소리와 실제 표기의 연결 정도
- 감으로 예상한 의미와 실제 해석의 차이
- 번역기와 한글 발음 힌트를 사용하는 순간
- 학습한 표현의 재인식·회상 여부

### Experience Research

실제 콘텐츠 감상, 대화, 읽기 상황에서 막힌 순간과 해결 행동을 기록합니다. 외부 인터뷰는 초기 MVP의 필수 조건으로 두지 않고, 다른 학습자로 확장할 때 진행합니다.

### 경쟁사 리서치

- Duolingo
- 말해보카
- 일본어 번역/사전 서비스

### 사용성 테스트

MVP를 실제 개인 학습에 사용하며 Task Test와 학습 로그를 함께 기록합니다.

결과를 바탕으로 IA, Result 화면, 학습 흐름을 수정합니다.

## Phase 3 — Learning System

추가 기능 후보:

- 저장 표현 복습
- 오답 기록
- 자주 헷갈리는 한자
- 자주 헷갈리는 가타카나
- 비슷한 발음 구분
- 개인별 복습 큐
- Recall Quiz

핵심 원칙:

> 서비스가 정한 단어보다 사용자가 실제로 궁금했던 표현을 우선 복습한다.

## Phase 4 — LISTEN Mode

실제 콘텐츠를 바탕으로 듣기 학습을 확장합니다.

Flow:

```text
듣기
→ 일본어 원문 객관식
→ 뜻 객관식
→ 정답 공개
→ 읽기/문법/표현 분석
→ 저장
```

오답 UX:

- 틀렸다는 사실은 명확하게 알린다.
- 강제로 반복시키지 않는다.
- `다시 해보기 / 다음으로` 선택권을 준다.

저작권과 라이선스를 우선 검토하며, 공식 링크·허용 가능한 콘텐츠 활용 방식을 설계합니다.

## Phase 5 — WRITE Mode Expansion

한국어로 생각한 문장을 일본어로 확장합니다.

추가 후보:

- 자연스러운 표현
- 캐주얼 표현
- 일기체
- 문학적 표현
- 비슷한 문장
- 상황별 뉘앙스 비교

전시, 여행, 일기, 음악 감상 등 사용자의 실제 삶에서 발견한 문장을 일본어 학습 콘텐츠로 전환합니다.

## Phase 6 — Personalization

사용자의 학습 기록을 바탕으로 개인화합니다.

- 최근 자주 틀린 한자
- 자주 검색한 표현 유형
- 관심 주제
- 복습 우선순위
- 추천 문장

추천은 무작정 새로운 학습량을 늘리기보다 기존 관심사와 오답을 중심으로 제공합니다.

## Phase 7 — Business Validation

검증할 질문:

- 반복 사용자가 생기는가?
- 어떤 기능에 가장 높은 가치가 있는가?
- 무료와 유료의 경계를 어디에 둘 것인가?
- AI 호출 비용 대비 지속 가능한 가격 구조가 가능한가?

초기 수익화 가설:

### Free

- 제한된 AI 검색
- 기본 뜻/읽기
- 제한된 저장

### Paid

- 검색 횟수 확대 또는 무제한
- 상세 뉘앙스/유사 표현
- 개인화 복습
- 저장·아카이브 확장
- Listening 학습 기능

가격과 기능은 실제 사용자 반응을 검증하기 전 확정하지 않습니다.

## Long-term Vision

단순 번역기나 단어장이 아니라, **일본 콘텐츠를 통해 이미 형성된 사용자의 청각적 일본어 지식을 실제 읽기·쓰기 능력으로 연결하고 자격증 학습에 들어갈 수 있는 기반을 만드는 제품**을 목표로 합니다.

소복이네 IP와 함께 하나의 독립적인 학습 브랜드로 확장할 가능성도 열어둡니다.
