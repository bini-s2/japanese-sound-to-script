## Phase 1 — HEARD MVP

V1 목표:

> 기억한 일본어 소리 하나를 정확한 표현으로 찾고, 오해한 이유를 이해한 뒤 저장하고, 최소한의 복습으로 다시 알아볼 수 있는지 검증한다.

핵심 기능:

- 한글 발음 입력과 선택형 맥락
- 일본어 후보 2~3개와 확신 수준
- 사용자의 후보 선택
- 표기·히라가나·한국어 의미
- 핵심 단어·활용·문법
- 유사음과 예상 의미 비교
- LocalStorage 저장
- 복습하기 버튼과 문제 수 직접 선택
- 표기 읽기→뜻 떠올리기→뜻 객관식
- 한국어 발음 기본 숨김과 알았어요 / 헷갈려요
- 찾던 표현 여부 피드백
- 무작위 단어·문장·혼합 표기 연습
- 히라가나·가타카나·생활 한자 선택 학습
- 자체 노래·상황 대화·소복이네 그림 퀴즈

기술 목표:

- 웹 기반 반응형 UI
- AI API 연동
- LocalStorage 저장
- 낮은 확신·정보 부족·오류 상태 구현

초기 합격선 가설:

- 실제 개인 사례 최소 10개
- 목표 표현이 상위 3개 후보에 포함되는 사례 10개 중 8개 이상
- 외부 검색 없이 후보를 선택하고 차이를 설명
- 사용자가 선택한 시점의 복습 결과와 저장 후 첫 복습까지 걸린 기간 기록

V1 제외:

- READ·WRITE 전체 모드
- 대규모 LISTEN 콘텐츠 라이브러리
- 상용 가사·음원·영상 DB
- 완성형 SRS와 JLPT 급수별 커리큘럼
- 로그인·결제·추천·소셜 기능

## Phase 2 — Learning Status & UX Validation

시험 점수보다 현재 학습 상태와 실제 사용 변화를 먼저 파악합니다.

### Learning Status Mapping

- 히라가나·가타카나 인식 속도
- 익숙한 소리와 실제 표기의 연결 정도
- 감으로 예상한 의미와 실제 해석의 차이
- 번역기와 한글 발음 힌트를 사용하는 순간
- 학습한 표현의 재인식·회상 여부

### Experience Research

실제 콘텐츠 감상, 대화, 읽기 상황에서 막힌 순간과 해결 행동을 기록합니다. 외부 인터뷰는 초기 MVP의 필수 조건으로 두지 않고, 다른 학습자로 확장할 때 진행합니다.

### 경쟁사 리서치

- Duolingo
- 말해보카
- 일본어 번역/사전 서비스

### 사용성 테스트

MVP를 실제 개인 학습에 사용하며 Task Test와 학습 로그를 함께 기록합니다.

결과를 바탕으로 IA, Result 화면, 학습 흐름을 수정합니다.

## Phase 4 — Original Song LISTEN Mode

일본어 가사만 표시되는 노래방과 유사한 조건을, 권리를 확보한 자체 제작 일본어 노래로 재현합니다.

### Learning Flow

```text
자체 제작 일본어 노래의 특정 구간 듣기
→ 들린 일본어 가사 객관식
→ 가사의 뜻 객관식
→ 정답과 전체 일본어 표기 공개
→ 히라가나·한자·가타카나·문법 분석
→ 저장 또는 다시 듣기
```

### Learning Intent

- 사용자는 처음에는 음원과 일본어 표기만 접한다.
- 한국어 발음과 번역은 정답 선택 전 노출하지 않는다.
- 노래를 통해 익숙한 소리를 실제 일본어 문자와 연결한다.
- 가타카나·한자 때문에 노래방 가사를 바로 읽지 못하는 문제를 안전한 학습 콘텐츠로 재현한다.

### Content & Rights Guardrails

- 서비스가 직접 작성·수정한 일본어 가사와 제작 방향을 사용한다.
- 특정 기존 곡·가수·캐릭터의 스타일, 목소리, 멜로디를 모방하도록 지시하지 않는다.
- 상업 이용이 명시적으로 허용된 AI 음악 도구와 생성 당시 요금제를 사용한다.
- 프롬프트·가사 초안·수정본·생성일·사용 도구·약관·라이선스 증빙을 보관한다.
- 생성 결과는 기존 곡과의 실질적 유사성을 검토한 뒤 사용한다.
- AI 산출물이라는 이유만으로 독점적 저작권이 자동 발생한다고 가정하지 않는다.
- 가능하면 가사 작성, 선곡, 편집, 편곡 등 인간의 창작적 기여를 명확히 남긴다.

### Error UX

- 틀렸다는 사실은 명확하게 알린다.
- 강제로 반복시키지 않는다.
- `다시 듣기 / 정답 보기 / 다음으로` 선택권을 준다.

상용 J-POP은 직접 수록하지 않으며, 향후 공식 임베드나 별도 라이선스를 확보한 경우에만 확장합니다.

## Phase 5 — WRITE Mode Expansion

한국어로 생각한 문장을 일본어로 확장합니다.

추가 후보:

- 자연스러운 표현
- 캐주얼 표현
- 일기체
- 문학적 표현
- 비슷한 문장
- 상황별 뉘앙스 비교

전시, 여행, 일기, 음악 감상 등 사용자의 실제 삶에서 발견한 문장을 일본어 학습 콘텐츠로 전환합니다.

## Phase 6 — Personalization

사용자의 학습 기록을 바탕으로 개인화합니다.

- 최근 자주 틀린 한자
- 자주 검색한 표현 유형
- 관심 주제
- 복습 우선순위
- 추천 문장

추천은 무작정 새로운 학습량을 늘리기보다 기존 관심사와 오답을 중심으로 제공합니다.

## Phase 7 — Business Validation

검증할 질문:

- 반복 사용자가 생기는가?
- 어떤 기능에 가장 높은 가치가 있는가?
- 무료와 유료의 경계를 어디에 둘 것인가?
- AI 호출 비용 대비 지속 가능한 가격 구조가 가능한가?

초기 수익화 가설:

### Free

- 제한된 AI 검색
- 기본 뜻/읽기
- 제한된 저장

### Paid

- 검색 횟수 확대 또는 무제한
- 상세 뉘앙스/유사 표현
- 개인화 복습
- 저장·아카이브 확장
- Listening 학습 기능

가격과 기능은 실제 사용자 반응을 검증하기 전 확정하지 않습니다.

## Long-term Vision

단순 번역기나 단어장이 아니라, **일본 콘텐츠를 통해 이미 형성된 사용자의 청각적 일본어 지식을 실제 읽기·쓰기 능력으로 연결하고 자격증 학습에 들어갈 수 있는 기반을 만드는 제품**을 목표로 합니다.

소복이네 IP와 함께 하나의 독립적인 학습 브랜드로 확장할 가능성도 열어둡니다.
