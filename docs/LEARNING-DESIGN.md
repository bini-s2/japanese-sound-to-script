# Learning Design

> Status: V1 learning flow defined  
> Scope: HEARD + COMPARE + SAVE + OPTIONAL REVIEW

## 1. Learning Goal

듣기와 문맥 감각이 먼저 발달한 학습자가 자신의 강점을 발판으로 가타카나·한자·회화·정확한 읽기를 더 빠르고 재미있게 익히게 합니다.

표현 하나의 학습 흐름은 다음과 같습니다.

```text
소리로 기억함
→ 일본어 표기를 찾음
→ 직접 읽어봄
→ 정확한 뜻과 구조를 이해함
→ 유사 후보·오해 지점을 비교함
→ 저장함
→ 원할 때 다시 읽고 뜻을 확인함
```

V1에서 “학습했다”는 표현은 완전 암기를 뜻하지 않습니다. 사용자가 저장한 표현을 다시 보았을 때 발음 힌트 없이 읽기를 시도하고 의미를 구분할 수 있는지를 확인합니다.

## 2. Learning Principles

1. **Japanese first** — 정답 결과에서는 일본어 표기를 가장 먼저 보여줍니다.
2. **Progressive reveal** — 읽기·뜻·문법을 한꺼번에 공개하지 않습니다.
3. **Romanization on demand** — 히라가나 옆의 작은 `(발음 보기)` 버튼을 눌렀을 때만 영문 로마자 발음을 보여줍니다.
4. **Context before guessing** — 노래 가사·식당 주문·지하철 질문 등 상황을 후보 추론과 문제 이해에 활용합니다.
5. **Compare every result** — 예상 의미를 적지 않아도 비슷한 후보의 차이는 항상 제공합니다.
6. **Review by choice** — 저장과 복습을 연결하되 자동 출제·알림·강제 반복을 사용하지 않습니다.
7. **Short feedback first** — 정답과 핵심 차이를 먼저 보여주고 문법은 펼쳐봅니다.
8. **No shame, no penalty** — 오답과 ‘헷갈려요’를 학습 데이터로만 사용하고 불이익을 주지 않습니다.

## 3. V1 Learning Loop

```text
CAPTURE
한글로 기억한 발음 + 선택적 상황·예상 의미

→ IDENTIFY
일본어 후보 2~3개 비교·선택

→ UNDERSTAND
일본어 표기 먼저 확인
읽기·뜻·문법을 단계적으로 펼치기

→ COMPARE
유사 후보 차이
예상 의미가 있다면 오해 원인 설명

→ SAVE
개인 표현장에 저장

→ OPTIONAL REVIEW
사용자가 ‘복습하기’를 눌러 학습
```

## 4. HEARD Result Learning Flow

### 4.1 Capture

필수 입력:

- 한글로 기억한 일본어 발음

선택 입력:

- 출처: 노래·애니·대화·여행
- 상황: 식당 주문·호텔·지하철·노래 가사 등
- 앞뒤에 기억나는 단어
- “나는 이런 뜻인 줄 알았어요”

선택 입력은 검색을 막지 않습니다. 후보가 모호한 경우에만 추가 맥락을 요청합니다.

### 4.2 Candidate Selection

후보 선택 단계는 정답 결과와 달리 선택에 필요한 최소 정보를 함께 제공합니다.

- 일본어 표기
- 히라가나 읽기
- 한 줄 의미
- 상황 또는 후보 간 핵심 차이
- 확신 수준 또는 “추가 맥락 필요”

후보는 최대 2~3개로 제한합니다. 어느 후보도 맞지 않으면 맥락 추가 또는 재검색으로 이동합니다.

### 4.3 Result — Progressive Disclosure

기본 노출 순서:

1. **일본어 표기** — 가장 크게 표시
2. **읽기·뜻 펼치기** — 사용자가 눌러서 확인
3. **핵심 단어·활용** — 짧게 표시
4. **유사 후보·오해 지점** — 핵심 차이 우선
5. **상세 문법** — 필요할 때 펼치기
6. **영문 로마자 발음** — 히라가나 옆의 작은 `(발음 보기)` 버튼으로 확인

영문 로마자는 정답의 중심 정보가 아니라 히라가나 읽기를 보조하는 임시 힌트입니다.

### 4.4 Compare

예상 의미를 입력하지 않은 경우:

- 비슷하게 들리는 후보
- 표기·뜻·상황의 차이
- 왜 이 후보가 현재 상황에 더 자연스러운지

예상 의미를 입력한 경우:

- 사용자가 예상한 의미
- 실제 의미
- 의미를 바꾼 핵심 단어·부정·활용·접속·조사
- 한 줄 설명 후 상세 문법 펼치기

### 4.5 Save

저장 정보:

- 일본어 표기
- 히라가나 읽기
- 한국어 의미
- 처음 입력한 한글 발음
- 상황·출처
- 예상 의미와 실제 의미의 차이
- 저장일
- 마지막 복습일
- 마지막 자기평가: 알았어요 / 헷갈려요

저장 후 바로 복습을 강요하지 않습니다.

## 5. Optional Review

### 5.1 Entry

사용자가 개인 표현장에서 **복습하기** 버튼을 눌러 시작합니다.

- 자동 복습 화면 없음
- 저장 직후 강제 문제 없음
- 일정 기반 알림 없음
- 연속 학습 스트릭·미복습 불이익 없음

개인 베타에서는 저장일과 사용자가 실제 복습을 선택한 날짜의 간격만 기록합니다.

### 5.2 Session Setup

사용자가 복습할 표현 개수를 직접 선택합니다.

- 선택 범위: 1개부터 현재 저장된 전체 개수까지
- 현재 저장 개수를 초과할 수 없음
- 이전에 ‘헷갈려요’를 선택한 표현을 우선 포함
- 남은 자리는 전체 저장 표현에서 무작위 선택
- 헷갈린 표현이 선택 개수보다 많으면 헷갈린 표현 중 무작위 선택

예:

```text
선택: 5개
헷갈린 표현: 2개
출제: 헷갈린 2개 + 전체 저장 표현 중 무작위 3개
```

### 5.3 One-expression Review Flow

#### Step 1 — 표기 읽기

- 일본어 표기만 먼저 보여줍니다.
- 사용자가 직접 소리 내거나 머릿속으로 읽습니다.
- ‘읽기 확인’을 누르면 히라가나 읽기를 보여줍니다.
- 히라가나 옆의 작은 `(발음 보기)` 버튼을 누르면 영문 로마자 발음을 표시합니다.
- 이 단계에서는 한국어 뜻을 공개하지 않습니다.

#### Step 2 — 뜻 떠올리기

- “이 표현은 무슨 뜻이었나요?”를 보여줍니다.
- 사용자는 정답을 보지 않고 뜻을 먼저 떠올립니다.
- 준비되면 ‘뜻 확인하기’를 누릅니다.

#### Step 3 — 뜻 객관식

- 한국어 의미 선택지를 제시합니다.
- 오답 선택지는 유사 후보·헷갈리기 쉬운 해석을 기반으로 만듭니다.
- 선택 후에만 정답을 공개합니다.

#### Step 4 — Feedback

정답인 경우:

- 정답 표시
- 핵심 의미 한 줄
- 필요하면 문법 펼치기

오답인 경우:

- 선택한 답과 정답을 명확히 구분
- 의미를 갈라놓은 핵심 단어·활용·문법 한 줄
- 상세 문법은 펼치기
- 강제 재도전 없음

#### Step 5 — Self-rating

답을 확인한 뒤 사용자가 직접 선택합니다.

- **알았어요**
- **헷갈려요**

‘헷갈려요’는 실패나 감점이 아닙니다. 다음 복습 세션에서 우선 출제하기 위한 신호로만 사용합니다.

## 6. Feedback Rules

- 틀렸다는 사실은 숨기지 않습니다.
- 오답 직후 전체 설명을 한꺼번에 펼치지 않습니다.
- 정답과 핵심 차이를 먼저 보여줍니다.
- 상세 문법·유사 표현은 사용자가 펼쳐봅니다.
- 같은 세션에서 강제로 다시 풀게 하지 않습니다.
- 학습 종료 뒤 헷갈린 표현 수는 보여줄 수 있지만 압박하는 문구는 사용하지 않습니다.

## 7. Learning State

V1에서는 과도한 숙련도 등급을 만들지 않습니다.

| State | Meaning |
|---|---|
| Saved | 표현을 저장했지만 아직 복습하지 않음 |
| Reviewed | 한 번 이상 선택 복습을 완료함 |
| Last: 알았어요 | 마지막 복습에서 사용자가 기억했다고 판단 |
| Last: 헷갈려요 | 다음 복습에서 우선 출제할 표현 |

한 번 ‘알았어요’를 눌렀다고 완전 학습 또는 암기 완료로 단정하지 않습니다.

## 8. Measurement

### Search & Understanding

- 검색부터 후보 선택까지 걸린 시간
- 목표 표현의 상위 3개 포함 여부
- 추가 맥락 요청 횟수
- 영문 로마자 발음 힌트 사용 여부
- 결과 저장 여부
- 외부 번역기 추가 사용 여부

### Optional Review

- 저장 후 첫 복습까지 걸린 기간
- 사용자가 선택한 문제 수
- 표기 읽기에서 발음 힌트를 연 횟수
- 뜻 객관식 정답률
- 알았어요 / 헷갈려요 비율
- 헷갈린 표현의 다음 복습 결과
- 복습 세션 중단 지점

정답률이나 복습 빈도를 사용자에게 경쟁 점수처럼 강요하지 않습니다. 개인 베타의 학습 변화와 제품 개선을 위한 관찰값으로 사용합니다.

## 9. Test Contexts

초기 테스트에는 다음 상황을 고르게 포함합니다.

- 노래 가사
- 식당에서 메뉴 주문
- 호텔 체크인·체크아웃·짐 보관
- 지하철에서 역·노선·출구 질문
- 직원의 예상하지 못한 긴 답변
- 정확한 음차
- 일부 음절 누락
- 장음·촉음 혼동
- 유사음
- 활용형
- 문맥에 따라 후보가 달라지는 표현

각 테스트 표현은 신뢰할 수 있는 사전·문법 근거 또는 별도 검토로 정답을 확인합니다.

## 10. Out of Scope

- 자동 복습 알림
- 강제 재도전
- 스트릭·리그·감점
- 완성형 SRS
- 숙련도 레벨 자동 판정
- 음성 인식 기반 발음 채점
- JLPT 급수별 진도
- 상용 노래 가사 복습
