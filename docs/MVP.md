# MVP Scope

## 1. V1 Goal

> 사용자가 기억한 일본어 소리 하나를 정확한 표현으로 찾고, 왜 그렇게 해석되는지 이해한 뒤 저장하고, 최소한의 복습으로 다시 알아볼 수 있는지 검증한다.

V1은 **HEARD + PRACTICE + COMPARE + MINIMAL REVIEW**로 구성합니다. 발음 검색을 핵심 가설로 유지하면서, 검색할 표현이 없는 순간에도 바로 학습할 수 있는 제한된 자체 콘텐츠를 함께 제공합니다.

## 2. Core User Story

> 일본 콘텐츠나 실제 상황에서 들은 일본어 발음은 기억나지만 정확한 표기를 모를 때, 한글로 들리는 대로 입력해 가능한 표현을 비교하고 실제 표기와 의미를 이해한 뒤 다음에는 직접 알아보고 싶다.

## 3. Core Flow

```text
한글 발음 입력
→ 선택적으로 맥락·예상 의미 추가
→ 일본어 후보 2~3개
→ 찾던 표현 선택
→ 표기·읽기·뜻·핵심 구조
→ 예상과 실제 의미 / 유사음 비교
→ 저장 또는 결과 피드백
→ 사용자가 원할 때 복습하기
```

## 4. Must-have Features

### 4.1 한글 발음 입력

예: 카와라나이 모노

정확한 음차를 요구하지 않습니다. 입력이 너무 짧거나 모호하면 결과를 지어내지 않고 맥락을 요청합니다.

### 4.2 선택형 맥락

필수 입력으로 만들지 않습니다.

- 들은 곳: 노래·애니·대화·여행
- 상황 예시: 노래 가사, 식당에서 메뉴 주문, 지하철에서 역·출구 묻기
- 앞뒤에 기억나는 단어
- 사용자가 예상한 의미

### 4.3 일본어 후보

최대 2~3개를 제공합니다.

- 일본어 표기
- 히라가나 읽기
- 한 줄 의미
- 후보를 구분할 짧은 맥락
- 확신 수준

### 4.4 후보 선택

사용자가 찾던 표현을 직접 선택합니다. 어느 후보도 아니라면 맥락을 보완하거나 새로 검색할 수 있습니다.

### 4.5 Result Detail

- 일본어 표기
- 히라가나·필요한 후리가나
- 자연스러운 한국어 의미
- 핵심 단어와 원형
- 핵심 문법 또는 활용
- 사용 맥락 라벨

설명은 핵심 정보부터 보여주고 상세 정보는 펼쳐봅니다.

### 4.6 Compare

COMPARE는 모든 결과에 포함합니다.

- 기본: 비슷하게 들리는 후보와 차이
- 예상 의미 입력 시: 예상과 실제 의미의 차이
- 차이를 만든 핵심 단어·활용·문법

“나는 이런 뜻인 줄 알았어요” 입력만 선택 사항입니다. 입력하지 않아도 후보 간 비교는 반드시 제공합니다.

### 4.7 Save

로그인 없이 LocalStorage 저장을 허용합니다.

저장 항목:

- 일본어 표기와 읽기
- 의미
- 처음 입력한 한글 발음
- 선택적인 출처·개인 메모
- 저장일

### 4.8 Minimal Review

저장한 표현은 사용자가 개인 표현장에서 **복습하기**를 눌렀을 때만 출제합니다.

1. 사용자가 문제 수를 직접 선택
2. 헷갈린 표현을 우선 포함하고 나머지는 전체에서 무작위 선택
3. 일본어 표기만 보고 읽기
4. 히라가나를 확인하고, 필요할 때만 옆의 작은 `(발음 보기)` 버튼으로 영문 로마자 발음 열기
5. 뜻을 먼저 떠올린 뒤 객관식으로 확인
6. 정답과 핵심 차이를 확인하고 알았어요 / 헷갈려요 선택

자동 일정, 알림, 완성형 SRS, 강제 반복은 포함하지 않습니다.

### 4.9 Learning Content Alpha

홈에서 다음 학습 콘텐츠에 진입합니다.

- 무작위 단어·짧은 문장·혼합 표기 연습
- 히라가나·가타카나 전체 표와 읽기 퀴즈
- 자주 쓰는 한자 표현 40개와 자연스러운 문장 문제: 최초 20개 노출, `더 많은 한자 표현 보기`로 다음 20개 추가
- 자체 상황 대화 5개 상황
- 현재 후보 135개에서 시작해 상한 없이 누적하는 실제 J-POP 제목 뜻 고르기·읽기·표현 분석 퀴즈
- 소복이네 그림 퀴즈 10개
- J-POP 제목은 검수 완료 풀에서 무작위 출제하며 한 세션에서 중복하지 않음

모든 문제는 일본어 표기 우선·영문 로마자 발음 기본 숨김·정답 후 핵심 설명 원칙을 공유합니다. J-POP은 제목과 가수명만 일반 텍스트로 사용하고, 실제 가사·음원·앨범아트·로고·영상 이미지는 서비스 DB에 직접 수록하지 않습니다.

### 4.10 Feedback

- 찾던 표현이에요
- 찾던 표현이 아니에요

부정 피드백에서는 재입력 또는 맥락 추가로 이어집니다.

## 5. Required States

- Initial
- Typing
- Optional Context Open
- Loading
- Multiple Candidates
- Candidate Selected
- Low Confidence
- Need More Context
- No Result
- Result Detail
- Saved
- Empty Saved List
- Review Setup
- Meaning Hidden
- Meaning Multiple Choice
- Pronunciation Hint Hidden
- Review Answer / Self-check
- Error

## 6. AI Output Guardrails

- 입력 하나에 정답 하나가 있다고 가정하지 않는다.
- 후보 수를 2~3개로 제한하고 차이를 설명한다.
- 낮은 확신을 명시하고 필요한 맥락을 요청한다.
- 문법 설명은 짧고 학습자 친화적으로 제공한다.
- 검증되지 않은 사용 빈도를 숫자로 표시하지 않는다.
- 상용 가사·음원·영상의 전문을 저장하거나 재배포하지 않는다.
- 사용자가 제공한 짧은 표현과 자체 예문으로 학습 구조를 검증한다.

## 7. Should-have Experiments

- “나는 이런 뜻인 줄 알았어요” 입력
- 저장 시 출처·메모

유용성과 입력 부담을 함께 확인하고 V1 구현 여부를 결정합니다.

## 8. Out of Scope

- WRITE 전체 모드
- 대규모 LISTEN 콘텐츠 라이브러리
- READ 이미지·텍스트 가져오기
- 상용 J-POP 가사·음원·영상 DB와 노래방 싱크
- 음성 인식·자동 구간 추출
- 로그인·결제·소셜·추천
- 완성형 SRS
- JLPT 급수별 커리큘럼
- 고급 개인화와 통계

## 9. Acceptance Targets

검증 전의 초기 합격선 가설입니다.

- 노래 가사·식당 주문·지하철에서 길 묻기 등 상황이 제시된 실제 개인 사례 최소 10개
- 정확한 음차·누락된 음절·유사음·활용형·문맥 의존 표현을 섞어 테스트
- 목표 표현이 상위 3개 후보에 포함되는 사례 10개 중 8개 이상
- 낮은 확신 사례를 단정하지 않고 표시
- 외부 검색 없이 후보를 선택하고 핵심 차이를 설명
- 사용자가 선택한 시점의 표기 읽기·뜻 고르기·영문 로마자 발음 확인 결과 기록
- 새로운 표현에서 같은 흐름을 다시 사용하는지 확인

함께 기록할 지표:

- 결과까지 걸린 시간
- 재입력·실패 비율
- 긍정/부정 피드백
- 저장률과 저장 이유
- 영문 로마자 발음 힌트 사용 여부
- 중단 지점
