# MVP Scope

## Goal

부트캠프 시작 전 첫 버전의 목표는 많은 기능을 구현하는 것이 아니라, 아래 핵심 경험이 실제로 유용한지 확인하는 것입니다.

```text
한글 발음 입력
→ 가능한 일본어 표기 제안
→ 읽기 / 뜻 / 표현 구조 확인
→ 저장
```

## Core User Story

> 일본 콘텐츠에서 들은 일본어 발음은 기억나지만 한자 표기를 모를 때, 한글로 들리는 대로 입력해서 실제 일본어와 뜻을 확인하고 싶다.

## MVP Features

### 1. 한글 발음 입력

예:

```text
카와라나이 모노
```

### 2. 일본어 후보 제안

AI가 가능한 표현을 추론합니다.

예:

```text
変わらないもの
かわらないもの
변하지 않는 것
```

후보가 여러 개라면 2~3개까지 보여주고 사용자가 선택할 수 있게 합니다.

### 3. 읽기 정보

- 자연스러운 일본어 표기
- 히라가나 읽기
- 필요한 경우 후리가나

### 4. 의미

- 가장 자연스러운 한국어 의미
- 직역이 필요한 경우 보조 설명

### 5. 표현 분석

최소한 아래를 제공합니다.

- 원형
- 활용 형태
- 핵심 문법
- 주요 단어

예:

```text
変わる → 変わらない
변하다 → 변하지 않는다
```

### 6. 비슷한 표현

과도하게 많이 보여주지 않고 2~3개만 제공합니다.

예:

- ずっと変わらないもの
- 変わらない気持ち
- いつまでも変わらない

### 7. 사용 맥락 라벨

초기에는 데이터 기반 점수 대신 정성적 라벨만 사용합니다.

예:

- 일상 회화
- 가사에서 자주 보임
- 캐주얼
- 문어적

### 8. 저장

유용한 표현을 개인 표현장에 저장합니다.

MVP에서는 로그인 없이 LocalStorage를 사용하는 방식도 허용합니다.

## UX Flow

```text
Home
↓
한글 발음 입력
↓
AI 분석 중
↓
표현 후보
↓
Result Detail
├─ 일본어
├─ 읽기
├─ 뜻
├─ 표현 분석
├─ 비슷한 표현
└─ 저장
↓
Saved Expressions
```

## Required States

디자인 단계에서 아래 상태를 반드시 포함합니다.

- Initial
- Typing
- Loading
- Success
- Multiple Candidates
- No Confident Result
- Saved
- Empty Saved List
- Error

## AI Output Guardrails

AI 결과를 그대로 신뢰하는 구조를 피합니다.

- 확신이 낮은 경우 단정하지 않고 후보를 제시한다.
- 입력이 너무 짧거나 맥락이 부족한 경우 추가 맥락을 요청한다.
- 문법 설명은 짧고 학습자 친화적으로 제공한다.
- 실제 사용 빈도는 검증된 데이터가 없으면 숫자로 표시하지 않는다.

## Out of Scope for MVP

아래 기능은 아이디어는 유지하되 첫 버전에서는 구현하지 않습니다.

- LISTEN Mode 전체 구현
- 실제 J-POP 가사 DB
- 영상 자동 구간 추출
- 음성 인식
- 회원가입/소셜 로그인
- 결제
- 고급 추천 알고리즘
- 장기 복습 스케줄링
- 개인화 모델
- JLPT 레벨 자동 분류
- 정교한 사용 빈도 통계

## Success Criteria

첫 버전은 아래 질문에 답할 수 있으면 성공입니다.

1. 사용자는 한글 발음 입력 방식을 바로 이해하는가?
2. AI가 제안한 일본어 표기가 실제로 도움이 되는가?
3. 결과 화면에서 어떤 정보가 가장 유용한가?
4. 사용자는 표현을 저장하고 싶어 하는가?
5. 같은 방식으로 다시 검색할 의향이 있는가?

## Pre-Bootcamp Target

부트캠프 전에는 완성도를 높이기보다 **작동하는 프로토타입을 직접 써보는 것**을 우선합니다.

완성 기준:

- [ ] 입력 가능
- [ ] AI 결과 반환
- [ ] 일본어/읽기/뜻 표시
- [ ] 간단한 표현 분석
- [ ] 저장
- [ ] 모바일/데스크톱 기본 반응형
- [ ] 최소 10개 이상의 실제 개인 사용 사례 테스트
