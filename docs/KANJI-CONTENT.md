# Frequent Kanji Expressions — V1

> Goal: 한자 자체를 외우기보다 실제로 자주 듣거나 보는 표현을 문장 안에서 소리·표기·뜻으로 연결한다.

## 1. Selection Principle

V1의 한자 학습 단위는 ‘한자 한 글자’가 아니라 **실제 단어와 표현**입니다.

선정 기준:

1. 노래·대화·여행에서 자주 접하는가
2. 사용자가 이미 소리로 알고 있을 가능성이 높은가
3. 히라가나만 알 때 읽기 흐름을 막는 표현인가
4. 짧은 문장으로 바로 사용할 수 있는가
5. 한 글자의 음독·훈독 암기보다 문맥으로 이해하는 편이 효과적인가

## 2. First 20 Expressions

전체 V1 콘텐츠는 최소 40개 표현으로 구성합니다. 아래 20개는 표에 처음 노출되는 1차 목록이며, 나머지 20개는 `더 많은 한자 표현 보기`를 누른 뒤 같은 표 아래에 추가됩니다.

| Expression | Reading | Meaning | Context | Example |
|---|---|---|---|---|
| 今日 | きょう | 오늘 | 일상·여행 | 今日は何をしますか。 — 오늘은 무엇을 하나요? |
| 明日 | あした | 내일 | 일상·약속 | 明日、東京に行きます。 — 내일 도쿄에 갑니다. |
| 昨日 | きのう | 어제 | 일상·회상 | 昨日、この歌を聞きました。 — 어제 이 노래를 들었습니다. |
| 今 | いま | 지금 | 일상·위치 | 今、駅にいます。 — 지금 역에 있습니다. |
| 時間 | じかん | 시간 | 일정·대기 | 時間はありますか。 — 시간 있나요? |
| 私 | わたし | 나·저 | 기본 자기표현 | 私は韓国から来ました。 — 저는 한국에서 왔습니다. |
| 僕 | ぼく | 나 | 남성적·부드러운 자기표현·가사 | 僕はこの歌が好きです。 — 나는 이 노래를 좋아합니다. |
| 君 | きみ | 너 | 친한 관계·가사 | 君のことを思っています。 — 너를 생각하고 있어. |
| 人 | ひと | 사람 | 인물 설명 | あの人は店員です。 — 저 사람은 직원입니다. |
| 心 | こころ | 마음·내면 | 감정·가사 | この歌を聞くと、心が落ち着きます。 — 이 노래를 들으면 마음이 편안해집니다. |
| 胸 | むね | 가슴·가슴속 | 신체·감정·가사 | 胸が苦しい。 — 가슴이 답답해. |
| 気持ち | きもち | 기분·마음·감정 | 감정 전달 | この気持ちを伝えたいです。 — 이 마음을 전하고 싶습니다. |
| 好き | すき | 좋아함 | 취향·감정 | 日本の音楽が好きです。 — 일본 음악을 좋아합니다. |
| 大切 | たいせつ | 소중함·중요함 | 관계·가사 | 君は大切な人です。 — 너는 소중한 사람이야. |
| 電車 | でんしゃ | 전철 | 여행 | この電車は渋谷駅まで行きますか。 — 이 전철은 시부야역까지 가나요? |
| 駅 | えき | 역 | 여행 | 駅はどこですか。 — 역은 어디인가요? |
| 出口 | でぐち | 출구 | 여행 | 出口はどこですか。 — 출구는 어디인가요? |
| 行く | いく | 가다 | 이동 | 明日、京都に行きます。 — 내일 교토에 갑니다. |
| 来る | くる | 오다 | 이동 | 友達が日本から来ます。 — 친구가 일본에서 옵니다. |
| 見る | みる | 보다 | 안내·행동 | この文字を見てください。 — 이 글자를 봐주세요. |

## 3. Meaning Differences

### 心・胸・気持ち

| Expression | Core meaning | Learning point |
|---|---|---|
| 心（こころ） | 마음·내면·정신 | 비교적 넓고 추상적인 마음 |
| 胸（むね） | 신체의 가슴·가슴속 감정 | 신체 감각 또는 가슴에 차오르는 감정 |
| 気持ち（きもち） | 현재 느끼는 기분·감정 | 특정 순간의 감정이나 상대에게 전할 마음 |

세 표현을 모두 ‘마음’이라고만 번역하지 않고 문장과 상황으로 구분합니다.

### 私・僕・君

| Expression | Core usage | Caution |
|---|---|---|
| 私（わたし） | 비교적 폭넓은 ‘나·저’ | 정중한 상황에서도 사용 가능 |
| 僕（ぼく） | 주로 남성이 쓰는 부드러운 ‘나’ | 가사·캐주얼 회화에서 자주 등장 |
| 君（きみ） | 친한 상대·가사 속 ‘너’ | 낯선 사람에게 쓰는 중립적인 ‘당신’은 아님 |

실제 일본어에서는 문맥상 분명한 주어를 자주 생략하므로, 한국어의 ‘나·너’와 일대일 대응한다고 가르치지 않습니다.

## 4. Irregular Word Readings

다음 표현은 글자별 대표 읽기를 조합하기보다 단어 전체의 읽기로 익힙니다.

- 今日 → きょう
- 明日 → あした
- 昨日 → きのう

문자 분해보다 자주 쓰는 문장과 함께 반복합니다.

## 5. Question Types

### Script → Reading

```text
今日

어떻게 읽을까요?
① きょう
② あした
③ きのう
```

### Script → Meaning

```text
君

무슨 뜻일까요?
① 나
② 너
③ 사람
```

### Sentence Context

```text
この電車は渋谷駅まで行きますか。

상황에 맞는 뜻을 고르세요.
```

### Similar Meaning

```text
마음·내면을 뜻하는 표현은?
① 心
② 胸
③ 駅
```

### Fill in the Sentence

```text
___はどこですか。
출구는 어디인가요?

① 出口
② 電車
③ 時間
```

## 6. Content Rules

- 표기만 먼저 보여주고 읽기·뜻은 단계적으로 공개합니다.
- 히라가나 읽기 옆에는 작은 `(발음 보기)` 버튼을 둡니다.
- 버튼을 누른 뒤에만 헵번식 로마자 발음을 보여줍니다. 예: `今日 → きょう  (발음 보기) → kyō`.
- 로마자는 보조 힌트이며 기본 상태에서는 숨깁니다.
- 한자 한 글자의 모든 음독·훈독을 한 번에 외우게 하지 않습니다.
- 각 표현은 최소 한 개의 자연스러운 문장과 연결합니다.
- 단어의 사용 관계·격식·가사적 뉘앙스를 함께 기록합니다.
- 사용자가 실제로 검색하거나 헷갈린 표현은 이후 목록에 우선 추가합니다.


## 7. Table Expansion

```text
자주 쓰는 한자 표현 20개
→ 더 많은 한자 표현 보기
→ 기존 목록 아래에 다음 20개 추가
→ 총 40개 표시
```

- 버튼은 표 바로 아래에 작은 텍스트 버튼으로 배치합니다.
- 문구는 `더 많은 한자 표현 보기`를 사용합니다.
- 기존 20개를 교체하지 않고 같은 표 아래로 확장합니다.
- 확장할 때 스크롤 위치를 유지합니다.
- 40개가 모두 표시되면 버튼을 숨깁니다.
- 다시 접는 기능은 V1에 넣지 않습니다.
