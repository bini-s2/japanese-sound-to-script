# Learning Status Map

> Date: 2026-09-16  
> Status: Initial baseline complete

## 1. Purpose

현재 목표는 특정 자격증 급수나 시험일에 맞춘 시험 대비가 아니다. 콘텐츠와 실전 경험을 통해 익힌 일본어가 문자·어휘·문법 지식으로 얼마나 연결되어 있는지 확인하고, 이후 자격증 학습에 들어갈 수 있는 기초를 만드는 것이 목적이다.

이 문서는 서비스의 초기 사용자 1호에 대한 방향성 진단이다. 표준화된 시험 결과가 아니므로 절대적인 등급 판정이 아니라 제품 설계와 학습 우선순위를 정하는 근거로 사용한다.

## 2. Method

- N5 수준의 기초 문항 15개
- 문자·어휘·한자·문법·문장 이해·콘텐츠 표현을 나눈 추가 진단
- 실제 콘텐츠 감상, 읽기, 대화 상황에서 겪은 행동 기록
- 정답 수뿐 아니라 오답 원인과 추론 과정 관찰

## 3. Quantitative Snapshot

| 영역 | 결과 | 해석 |
| --- | ---: | --- |
| N5 기초 문항 | 약 7~8/15 확실 | 안정적인 N5 수준은 아니며 영역 편차가 큼 |
| 히라가나 어휘 | 2/3 | 기본 인식은 가능하지만 속도·정확도가 불안정 |
| 가타카나 | 0/4 | 현재 가장 큰 문자 공백 |
| 한자 | `日本` 정도만 확실 | 청각 어휘에 비해 문자 어휘가 매우 제한적 |
| 기초 문법 | 4/4 | 명시적 학습량보다 문법 감각이 앞서 있음 |
| 문장 이해 | 2/3 | 문맥과 아는 단어를 이용한 의미 추론이 강함 |
| 콘텐츠 표현 | 강점 | 반복 노출된 소리·표현·뉘앙스를 잘 기억함 |

## 4. Representative Error

```text
コンビニで アイスを かいました
```

`かいました`를 ‘샀습니다’가 아니라 ‘갔습니다’로 해석했다.

이 오류는 단순한 단어 부족보다 다음 특징을 보여준다.

- 들리거나 익숙한 형태를 먼저 떠올린다.
- 문자 형태를 끝까지 구분하기보다 문맥상 가능한 의미를 빠르게 선택한다.
- `買いました`와 `行きました`처럼 활용형이 포함된 동사를 문자 단위로 정확히 구분하는 연습이 필요하다.

## 5. Observed Behaviors

### Listening & Speaking

- 익숙한 상황에서는 필요한 질문을 일본어로 만들 수 있다.
- 시간·장소·숫자 등 핵심 정보는 문맥과 함께 포착하는 경우가 있다.
- 준비한 질문은 말할 수 있지만 예상하지 못한 긴 답변에서는 세부 정보를 놓치기 쉽다.
- 콘텐츠에서는 아는 단어와 목소리·멜로디·상황을 결합해 전체 뉘앙스를 추론한다.

### Reading

- 히라가나는 천천히 읽을 수 있지만 실시간 속도를 따라가기 어렵다.
- 한글 발음이 있으면 이를 힌트로 일본어 문자를 따라 읽는다.
- 가타카나와 한자가 나오면 읽기 흐름이 크게 끊긴다.
- 일본어 텍스트를 만나면 직접 해독하기보다 전체 번역을 먼저 사용하는 경향이 있다.

### Meaning

- 아는 단어와 분위기를 이용한 의미 추론은 강하다.
- 부정, 반전, 접속, 생략된 주어를 놓치면 실제 문장 의미를 반대로 이해할 수 있다.
- 정답 번역만 확인하면 왜 처음의 해석이 달랐는지 학습으로 남지 않는다.

## 6. Skill Gap Map

| Strength | Developing | Major Gap |
| --- | --- | --- |
| 콘텐츠 기반 청각 기억 | 히라가나 읽기 자동화 | 가타카나 인식 |
| 문맥·상황 추론 | 짧은 문장의 정확한 해석 | 한자 어휘 |
| 기초 문법 감각 | 예상 밖 답변의 세부 듣기 | 문자 기반 어휘량 |
| 익숙한 상황의 실전 회화 | 소리와 활용형 연결 | 번역기 없이 읽기 |
| 표현의 정서·뉘앙스 감지 | 의미 예상 후 검증 | 긴 문장의 구조 분석 |

## 7. Learner Profile

> 청각·문맥 능력이 문자 지식보다 크게 앞선 비대칭형 학습자

완전 초보자용 커리큘럼은 이미 알고 있는 표현을 반복하게 만들 수 있고, 사전·번역기는 당장의 이해만 해결한다. 필요한 것은 기존 청각 지식을 문자와 정확한 의미로 전환하는 연결 학습이다.

## 8. Product Implications

1. **Sound-first entry**  
   한국어로 기억한 발음을 입력하고 일본어 후보를 비교한다.

2. **Script contrast**  
   비슷하게 들리거나 보이는 표현을 나란히 비교한다.

3. **Progressive hint removal**  
   한글 발음은 임시 힌트로 제공하고 익숙해질수록 숨긴다.

4. **Prediction gap feedback**  
   사용자가 예상한 뜻과 실제 뜻이 어디에서 달라졌는지 설명한다.

5. **Translation-to-learning**  
   전체 번역 전에 읽기·어절·문법을 단계적으로 확인한다.

6. **Interest-led recall**  
   실제로 궁금했던 표현과 오답을 저장해 다시 회상한다.

7. **Respect prior knowledge**  
   이미 아는 소리·문법은 건너뛰고 문자 공백에 집중한다.

## 9. Initial Measurement Criteria

- 한글 발음 없이 읽는 표현 수
- 가타카나 즉시 인식률
- 전체 번역을 열기 전 직접 읽어본 비율
- 예상 의미와 실제 의미의 차이를 설명한 비율
- 저장한 표현의 재인식·회상 정확도
- 짧은 답변에서 시간·장소·방향 정보를 잡는 정확도
- 동일 표현을 다시 만났을 때 번역기 없이 이해한 비율

## 10. Conclusion

현재 핵심 과제는 새로운 회화 표현을 많이 추가하는 것이 아니라, 이미 귀에 축적된 일본어를 빠르고 정확하게 읽을 수 있는 문자 지식으로 전환하는 것이다. 초기 MVP는 이 비대칭을 줄이는 하나의 짧은 학습 루프를 검증해야 한다.
